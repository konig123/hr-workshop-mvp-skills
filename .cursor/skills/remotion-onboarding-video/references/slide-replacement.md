## 學員如何替換自己的投影片（For Students）

若學員希望將上述預設素材換成自己公司的入職投影片：

1. **準備簡報圖片**：
   - 格式：PNG 或 JPG。
   - 建議比例：**16:9**（1280×720 或 1920×1080 高清解析度）。
   - 匯出方式：可直接從 PowerPoint / Google Slides / Keynote 選擇「檔案 → 匯出為 PNG 圖片」。

2. **放入專案資料夾**：
   - 將導出的圖片放至目前 Remotion 專案的 `public/slides/` 目錄中。
   - 建議檔名按順序命名（例如 `slide-01.png`, `slide-02.png` 等）。

3. **修改旁白與場景對應**：
   - 告知 Agent：「我想使用自己放入的投影片，共有 X 張，每張的重點分別是……」
   - Agent 會自動根據學員的投影片內容，重新撰寫廣東話/英文旁白稿件並產生對應的合成語音與時間軸切換。
