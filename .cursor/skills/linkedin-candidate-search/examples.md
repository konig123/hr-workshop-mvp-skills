# Examples

## hiring-requirements.md (drop into `hiring-requirements/`)

```markdown
# Hiring requirements

- Culture: tech company, startup culture
- Salary: HKD 50K–70K monthly
- Other: LinkedIn follower of the hiring company
- Location: Hong Kong or Singapore; prefer current right to work
```

## JD file

Paste the full JD, or a single URL:

```text
https://job-boards.greenhouse.io/abc-company/jobs/1234567
```

## Kickoff

User: run linkedin-candidate-search

Agent: lists `JD/` and `hiring-requirements/` (or offers to create them) → user picks one file each → agent searches public LinkedIn → writes `{role}-linkedin-shortlist.canvas.tsx`.
