# Step 3 � Storyline Plan

Turn insights + charts into an executive narrative. No layout, CSS, or output files.

**Input:** Insight Brief (Step 1) + Chart Plan (Step 2).

Adapt arc to deck type:

| Deck type | Typical arc |
|-----------|-------------|
| Pulse / engagement survey | Paradox ? risks ? segments ? actions |
| Year-end HR performance | Year in review ? KPIs ? programs ? challenges ? 2026 priorities |
| Board / CHRO briefing | Situation ? results ? risks ? ask |

## Agent output format

### A. SCQA frame

- **Situation:** what leadership already believes (1�2 sentences)
- **Complication:** tension, gap, or year-end headline
- **Question:** one decision question this deck answers
- **Answer:** 3-part answer in plain language

### B. Slide map (8�12 slides)

| # | Slide title | Chart ID | Template | Narrative job (1 sentence) | Insight callout |
|---|-------------|----------|----------|----------------------------|-----------------|
| 1 | | � | A | | |
| 2 | | CH-01 | B | | |
| 3 | | � | D | | |
| 4+ | | CH-XX | C | | |
| last | | � | E | | |

Templates: A=Title, B=Headline+KPI, C=Data, D=Scope/section, E=Actions/close

### C. Slide 2 headline (exact wording)

One sentence; mark **emphasis phrases** for italic:

> Example (survey): Our people are **proud** � but **3 in 4** lack resources to execute.
> Example (year-end): HR delivered **92%** of hiring targets � while **burnout risk** rose in Q4.

### D. Final slide actions (exact wording)

- Action 01: title + 1 sentence
- Action 02: title + 1 sentence
- Action 03: title + 1 sentence
- Timeline banner: one sentence with next steps

### E. Speaker flow (optional)

One line per slide: **Say** ? **Show (chart ID)**

### F. Cut list

Insights from Step 1 not in deck; appendix option.

## Rules

- SCQA order across deck
- One primary visual per data slide
- Every data slide: one insight callout with a bold stat (or quoted theme if qualitative-only text input)
- Text-only input: allow qualitative slides but flag where numbers would strengthen the story
