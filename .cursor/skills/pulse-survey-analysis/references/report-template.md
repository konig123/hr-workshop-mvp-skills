# Company Pulse PDF template (8 sections)

Matches `Company Pulse Survey Report - YYYY-MM.pdf`.

## Header / footer

- Title: `Pulse Survey Team Report — {Team} ({period})`
- Footer centre: `{Team} Pulse · {period}`
- Page number top-right
- A4, 22 mm margins, Helvetica, navy `#1F3864` / accent `#4472C4`

## Preamble + Summary (page 1)

- Explain **Direct Leader** (Q1–Q10) vs **Overall** (all 20).
- Structural map: Leader · Dept Head · Team · Engagement.
- Note missing invitation roster → response-rate cells show completed **n** only.
- Note missing open-text if absent.
- Summary: completions, company pillar vs blended, top pillar scorer, operating priority bullets.
